FAQ

Short answers.

Does aki change anything on GitLab, GitHub or Jira?

No. It only reads. It has no action that approves, merges, comments, transitions or pushes. Enter opens the page in your browser; you act there.

Where does my data go?

Nowhere but your machine. aki talks to your own sources with your own tokens, and keeps a local cache of who spoke when. It has no server and no account. The cache holds neither the text of comments nor any token.

Why does it poll instead of receiving events?

None of the three services pushes events to a personal client. aki asks every 30 seconds and keeps it cheap: a few light requests, and discussions read again only when an item moved.

A task is missing. Why?

  • It asks nothing of you and you wait on nothing: an approved change of someone else's, for example.
  • It is set aside: look at a pane filtered on is:snoozed.
  • It is a draft of yours kept apart or ignored: see Drafts.
  • Its rule is turned off: aki rules shows which are on.
  • The space's scope or the pane's filter leaves it out: I shows both.
  • On GitLab, you only commented on it: see Known limits.

Why is this task above that one?

i on each: the window lays the urgency out line by line. If the pane is not ordered by urgency, its title says by what.

How do I keep my drafts out of "To do"?

mine = "apart" under [drafts], and a pane filtered on is:draft role:author. See A pane for your drafts.

Can I use two accounts of the same service?

Yes: declare two sources of that kind with different name, host or token. See Sources.

Does it work with a self-hosted GitLab or GitHub Enterprise?

Set host on the source. Jira is Cloud only.

Which agent does a open?

Claude Code by default. Any command works: set command under [agent]. See Agents.

Can I use it without a terminal?

Yes, through an assistant: aki mcp serves the board to Claude Desktop or any MCP client. See Assistants. aki itself still has to be installed on the machine.

Does it run on Windows?

It is developed and used on macOS. The Linux paths (notifications, sounds, opening links) are written but have not been tested yet. It has not been run on Windows.

What does the name mean?

À qui ? is French for "whose turn?".
