Working from it

Assistants

aki serves the board to an assistant over the Model Context Protocol, for whoever would rather ask than open a terminal.

Once plugged in, the assistant can be asked: what waits on me, why is this one first, set that one aside until Monday, start on the review of web!916.

Plug it in

aki mcp setup

This prints the block below with the full path of your aki.

Settings › Developer › Edit Config, add this to claude_desktop_config.json, and restart the app:

{
  "mcpServers": {
    "aki": { "command": "/Users/you/.cargo/bin/aki", "args": ["mcp"] }
  }
}
claude mcp add aki -- aki mcp

Any MCP client that starts a server on standard input and output: the command is aki mcp.

aki must be installed and its sources signed in on the same machine. An app started outside a shell passes a short PATH; aki adds /opt/homebrew/bin, /usr/local/bin, ~/.local/bin and ~/.cargo/bin so that glab and gh are found.

Tools

ToolDoesArguments
list_tasksThe board, most urgent first. Every task says why it is listed and how its score is made.side, space, filter, sort, limit
get_taskOne task in full: its reasons, its urgency line by line, its links, and the brief of what is expected.reference
list_spacesYour spaces, their panes, the repositories they hold.
explain_rulesEvery rule as configured, and how urgency is computed.
set_asideHide a task for a number of days, or until it moves.reference, days
bring_backPut a task that was set aside back on the board.reference
start_agentOpen your agent on a task, through the launcher you chose.reference

A reference is what the board shows: web!916, notes#12, PROJ-7, a ticket key, or the URL. filter takes the same queries as a pane.

What it may do

Reading the board is always allowed. The rest is yours to say:

~/.config/aki/config.toml
[mcp]
enabled = true
set_aside = true
start_agent = true
KeyWhen false
enabledaki mcp refuses to start.
set_asideset_aside and bring_back are neither offered nor done.
start_agentstart_agent is neither offered nor done.

No tool approves, merges, comments or pushes: aki has no such action.

Starting work from a conversation

Without a terminal, start_agent opens a new Claude conversation on the task's brief:

[agent]
launcher = "claude"

With launcher = "auto", this is also what happens when aki finds neither Herdr nor a terminal. To work on the task in the conversation at hand instead, ask for the task: get_task returns the same brief.
