Start

Install

One command builds aki and tells you what to sign in to.

curl -fsSL https://nathan-poncet.github.io/aki/install.sh | sh

The script builds aki from its repository with Cargo and installs one program, aki, in ~/.cargo/bin. It then tells you whether glab and gh are present. It installs nothing else and needs no administrator rights.

Requirements

  • macOS or Linux.
  • The Rust toolchain (cargo). Without it the script stops and says so; AKI_RUSTUP=1 lets it install the toolchain with rustup first.
  • git.
  • For GitLab, the glab CLI; for GitHub, the gh CLI. aki uses their logins. A token in an environment variable works too: see Sources.

Other ways

cargo install --locked --git https://github.com/nathan-poncet/aki
git clone https://github.com/nathan-poncet/aki
cd aki
cargo install --path .
curl -fsSL https://nathan-poncet.github.io/aki/install.sh | AKI_REF=main sh

AKI_REF is a tag, a branch or a commit.

Sign in

aki reads each service with the login of its own CLI. Sign in to the ones you use:

glab auth login
or
gh auth login

Jira needs three lines of configuration: see Sources.

Check

aki doctor

It prints one line per source: who you are signed in as, or why the source cannot be read.

Update

Run the install command again. Cargo rebuilds only when the sources changed.

Uninstall

cargo uninstall aki
rm -rf ~/.config/aki ~/.cache/aki ~/.local/state/aki

The second line removes your configuration and spaces, the cache, and what you set aside.
