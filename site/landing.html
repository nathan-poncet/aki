What it plugs into

  
aki runs on your machine and signs in with the tools you already have. It only reads your sources: it never approves, merges, comments or pushes.

  

    
    

      
It reads

      GL
GitLabmerge requests · threads · approvals · pipelinesgitlab.com or self-hosted · signs in with glab

      GH
GitHubpull requests · reviews · checks · issuesgithub.com or Enterprise · signs in with gh

      J
Jira Cloudtickets · status · priority · blockersan API token · three lines of configuration

    

    

      
      aki
      reads · decides · remembers
      on your machine · local SQLite cache · no account, no server
    

    

      
It shows you

      ▦
The boarda terminal interface, refreshed every 30 seconds

      $_
The command linea list, a count for a status bar, JSON

      ♪
Notifications and soundswhen something new becomes yours

      
It answers over MCP

      ✳
MCP serverClaude Code · Claude Desktop · any MCP clientlist_tasks · get_task · set_aside · start_agent…

      
It hands a task over

      ▸
Your coding agentClaude Code by default, or any command, briefed on the taskin Herdr · tmux · TUIOS · Ghostty · WezTerm · kitty · iTerm · Terminal · or a Claude conversation
