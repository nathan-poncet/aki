aki config init

This writes ~/.config/aki/config.toml with every setting at its default and a comment on each. aki config path prints where the file is. Unknown keys and names are errors.

Files

FileHolds
~/.config/aki/config.tomlThe settings on this page. $AKI_CONFIG names another file; $XDG_CONFIG_HOME is honored.
~/.config/aki/spaces.tomlYour spaces, rewritten when you rearrange the board.
~/.cache/aki/cache.dbWhat was read from the sources (SQLite). $XDG_CACHE_HOME is honored.
~/.local/state/aki/snoozed.jsonWhat you set aside. $XDG_STATE_HOME is honored.

General

refresh_seconds = 30
notifications = true
cache_seconds = 60
KeyMeaning
refresh_secondsHow often the board looks again. Minimum 5.
notificationsA desktop notification when something new becomes yours.
cache_secondsaki list reuses a reading younger than this. 0: always ask.
